# Architecture Decision Records

ADRs in this folder record decisions that later work should follow. One file, one decision. The number is permanent: a later decision supersedes an earlier one by naming it, and does not reuse its number.

## Format

File name: `NNNN-short-title.md` (four digits, then a kebab-case title).

Each ADR uses these sections:

- **Status** — Proposed, Accepted, or Superseded, with who accepted it and when.
- **Decided by** — The person who owns the decision.
- **Related** — Issues, PRs, and docs this decision depends on or changes.
- **Context** — The situation that forced a choice.
- **Decision** — What was chosen.
- **Consequences** — What follows, including docs or code that still disagree.

Accepted text stays as written. A change of mind is a new ADR.
